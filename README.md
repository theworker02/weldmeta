# weldmeta

Weld identifiers and meta tokens for idempotent workflows.

**Site:** https://theworker02.github.io/weldmeta/

## Install / run

```bash
git clone https://github.com/theworker02/weldmeta.git
cd weldmeta
node src/cli.js
node --test
```
